# Exercise solutions

My version of each in-class exercise can be found here.

```{tip}
Only use the solutions as a last resort.

If you do use these solutions, attempt to

1. understand my solution, and 
2. write the solution yourself based on what you understand.

You'll learn much more that way!
```

```{tip}
Once you've completed an exercise, I do recommend comparing your solution to mine. It is possible I solved the same problem using a different approach than you, which can help with learning!
```
